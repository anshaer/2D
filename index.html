使用流程

  1. 在製作器載入圖片或角色專案 ZIP，建立網格與姿態。
  2. 勾選「VMC 接收（手機／平板）」取得 12 碼。
  3. 手機／平板選控制區域、輸入相同碼並連線。
  4. 確認動作後匯出角色 HTML，或 HTML＋圖檔 ZIP。
  5. 匯出角色頁預設隱藏設定；點角色顯示設定，再配對新碼。

原角色專案 ZIP 可載入。舊角色 HTML 要使用新版多來源功能，請在 v2.14.0 重新匯出。製作頁與角色頁使用各自的碼。

控制與限制

服裝與表情圖片組仍可疊加；手機滑動或平板方向按鈕可切換。頭部、眼睛、眉毛、嘴型分開取值，避免其他區域覆蓋。

2D 仍使用面部與頭部訊號，3D 肢體骨骼不會自動變成 2D 圖層動作。多來源是控制分工，不是多鏡頭融合。手機相機須 HTTPS，配對需網路。
