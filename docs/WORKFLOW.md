# 2D 製作與角色匯出

## 原專案

在 https://anshaer.github.io/2D/maker.html 載入角色專案 ZIP，保留原圖片、網格、姿態、圖片組與設定。此次沒有修改角色圖檔。

新增圖片時設定圖層位置、縮放、旋轉與圖層群組。長寬網格密度依拆件分別設定。
先設定基準姿態，再用面部模擬建立閉眼、嘴型與轉頭等姿態。VMC 接收開啟時，模擬控制由遠端資料接管；要手動編輯模擬值先停用 VMC。

## 面捕測試

勾「VMC 接收（手機／平板）」，電腦產生碼。手機做辨識或平板手動合成。
傳送端選整面或分區，控制值送到製作器，不在電腦再次加靈敏度／鏡像／平滑。
角色是否閉眼、張嘴或轉頭，依角色專案已設定的姿態與網格，不是只連線就能自動建立拆件與動作。

## 圖片組

ALT＋0～9 的圖片組設定沿用原專案。
手機／平板傳 up/down/left/right，製作器依既有服裝／表情分類切換：左右為服裝，上下為表情。
這些方向事件不會被面部影格覆蓋；服裝與表情仍可疊加。
未設定對應圖片組時，接收事件不會憑空產生服裝或表情素材。

## 專案 ZIP 與角色頁

- 專案 ZIP：供製作器繼續編輯，含 project.json 與圖片。
- 單一角色 HTML：角色素材嵌入，分享或 OBS 使用。
- 角色 ZIP：HTML＋圖檔；設定與控制程式仍在 HTML。

匯出可設定檔名、版權與頁簽名稱。空版權不顯示，製作器本身頁尾固定顯示作者版權。
角色頁預設只顯示角色與選填版權；點角色顯示設定。拖移配合滾輪縮放，適合上半身取景。

## 新版 VMC

匯出會保留開關，但重新產生碼。不要把製作頁的碼當成角色頁的碼。
角色頁在 HTTPS 網址可以複製帶當前碼的 OBS 接收網址；先關閉占用同碼的舊頁，再讓 OBS 載入並確認實際碼。
同時開製作頁與角色頁時，它們是兩個接收端；傳送端需選擇要控制哪一頁。

舊角色 HTML 要使用 v2.14 的分區接收，需要由原角色專案重新匯出。
