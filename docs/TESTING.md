# 驗證與限制

已通過：

- 製作頁／角色頁產碼、一維碼、QR、手機配對。
- VMC 開啟不啟動電腦相機，不重複加靈敏度與模擬覆蓋。
- 轉頭、眼睛、眉毛、嘴型、深度套用與逾時清除。
- 製作頁與角色頁四來源頭部／眼睛／嘴型分工、優先與3秒備援。
- 服裝／表情切換疊加與不同來源方向確認。
- 實際HTML的手機傳送區域選單與兩台平板連接診斷頁。
- playerHTML 真實DOM匯出、設定預設隱藏、保留VMC開關、清除臨時碼／QR。
- 角色ZIP外置圖片、設定與runtime留在HTML。
- 停用VMC／關頁的連線與計時器清理。

使用模擬Peer與DOM，未完成實體手機、平板、OBS Browser Source與實際角色素材的全流程視覺驗證。
素材動作依既有姿態記錄與網格配置，連線本身不會替未綁定的圖片產生閉眼或嘴型。
第三方模型下載、網路穿透與瀏覽器權限仍受環境影響。

角色ZIP測試包含測試圖片fixture，該fixture不作為本包角色素材提供。
